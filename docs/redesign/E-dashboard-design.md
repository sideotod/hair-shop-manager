## E2. 월별 차트 (§11.1)

```
질문             올해 어느 달이 잘 되고 어느 달이 나쁜가?
지원하는 결정    비수기 대비, 판촉 시점 선택, 작년 같은 달과 비교
데이터 출처      RevenueAggregate(granularity: "monthly", year: YYYY)
갱신 시점        페이지 로드 (서버 렌더)
빈 상태          해당 연도에 거래가 하나도 없으면 "2027년 매출 기록이 없습니다"
오류 상태        집계 실패 시 카드 자리에 오류 메시지 + 재시도 링크
왜 이 차트 유형  12개 고정 구간의 크기 비교 = 세로 막대.
                 선 차트는 "연속 추세"를 뜻하는데 월은 이산 구간이다.
```

**형태:** 세로 막대 12개. 1월부터 12월까지 **항상 12개 전부** 그린다.

**금액 정렬 금지.** x축은 1→12월 고정. 어떤 상황에서도 금액순으로 재정렬하지 않는다.

**델타:** 각 막대 위에 전월 대비(MoM). 카드 헤더에 선택 연도 전체의 전년 대비(YoY).

| 표기 | 규칙 |
|---|---|
| 증가 | `▲ 12.4%` — `--success` |
| 감소 | `▼ 8.1%` — `--danger` |
| 전월 0원 | `신규` — 퍼센트 계산 불가. `Infinity` 출력 금지 |
| 전월 데이터 없음 | `—` |

**상태 구분 (§18):**

| 상태 | 표현 |
|---|---|
| 실제 0원 | 높이 0의 막대 + 축 위 얇은 기준선. 값 `₩0` 표시 |
| 데이터 없음 | 막대 없음. 축 위치에 점선 자리표시 + 라벨 회색 |
| 미래 기간 | 막대 없음 + 라벨 `--muted` 40% 불투명 |
| 진행 중 | 막대는 그리되 **"진행 중" 텍스트 라벨**. 별도 색 아님 (DESIGN.md §3.4) |

**상호작용:** 막대 클릭 → 해당 월의 일별 차트로 전환 (`/sales?view=month&cursor=YYYY-MM-01`).

## E3. 일별 차트 (§11.2) — 최우선 수정 대상

```
질문             이번 달 어느 날 매출이 나왔고 어느 날 비었나?
지원하는 결정    휴무일 확인, 요일별 패턴 파악, 특정일 거래 확인
데이터 출처      RevenueAggregate(granularity: "daily", month: YYYY-MM)
갱신 시점        페이지 로드
빈 상태          그 달에 거래가 없으면 축은 그대로 그리고 "8월 매출 기록이 없습니다"
오류 상태        위와 동일
왜 이 차트 유형  하루 매출은 이산값이다. 선은 두 날 사이를 이어 연속량처럼 읽히는데,
                 실제로는 문 닫은 날과 장사한 날이 번갈아 온다.
                 2026-07은 31일 중 10일이 실제 ₩0인데 선으로 그리면 그 열흘이
                 "완만한 하락"으로 보인다(실측). 막대는 각 날을 끊어 세운다.
                 바로 아래 월별·연도별이 이미 세로 막대라 문법도 하나로 모인다.
```

**형태:** 세로 막대. x축은 **1일부터 그 달 마지막 날까지 전부** (28/29/30/31일 자동).

> 초안은 "막대 31개는 1208px에서 각 폭 30px로 눌려 읽기 어렵다"는 이유로 선 차트를 택했다.
> 1440px에서 실측하니 칸 폭은 32.4px, 막대는 `max-w-[18px]`로 캡되어 칸 사이에 14px 간격이 남는다.
> 전제가 틀렸으므로 결론을 뒤집는다.

**현행 대비 핵심 변경:**

| 현행 (A2-4) | 재설계 |
|---|---|
| 거래가 있는 날짜만 축이 됨 | 달력 전체가 축 |
| 8/4, 8/5, 8/6이 화면에서 사라짐 | 8/1~8/31 전부 표시 |
| 실제 0원과 데이터 없음 구분 불가 | 시각적으로 구분 |
| 차트가 아니라 목록 | 세로 막대 차트 |

**상태 구분 (§18):**

| 상태 | 표현 |
|---|---|
| 실제 0원 (거래 0건) | 막대 없음 + 바닥에 `--muted` 2px 눈금. 값 `₩0` |
| 데이터 없음 | 막대도 바닥 눈금도 없는 빈 칸. x축 라벨은 유지 |
| 미래 날짜 | 빈 칸. 클릭 대상이 아니다(링크가 아니라 `span`) |
| 진행 중 (오늘) | 막대 + 골드 점선 테두리 + 세로 골드 기준선 |
| 정정 있는 날 | 막대 전체를 골드 그라디언트로 (DESIGN.md §4.1 승인된 골드 용도 2 중 하나) |

바닥 눈금은 `--border`가 아니라 `--muted`다. `--border`는 우물 배경 위에서 1.1:1이라
"실제 ₩0"과 "빈 칸"이 눈으로 구분되지 않았다(실측). 이 눈금은 장식이 아니라 상태 정보다.

**날짜 조작 금지.** 없는 날짜를 만들지 않고, 있는 날짜를 빼지 않는다.

**합계 항등식:** 카드 헤더의 "8월 총 매출"이 차트 모든 점의 합과 **정확히 일치**해야 한다. 테스트로 강제 (산출물 G §G6).

**상호작용:** 막대·빈 칸 어디든 그 날 칸 전체가 클릭 영역 → `/sales/transactions?view=day&cursor=YYYY-MM-DD`. 미래 날짜는 링크가 아니다.

**값 표시:** DESIGN.md §3.4가 "막대 끝에 금액 상시 표시(hover tooltip 사용 안 함)"를 규정한다. 31개 막대 전부에 금액을 상시 표시하면 1440px에서도 겹친다(칸 폭 32.4px, `₩294,000`은 약 56px). 상시 라벨을 포기하고 hover·focus 말풍선을 쓴다. 금액을 잃지 않는 경로는 세 갈래로 남긴다 — 카드 헤더의 월 총액, 칸마다의 `aria-label`(`13일 ₩294,000. 거래 목록 보기`), 그리고 31행 전체를 담은 `sr-only` 표. 월별·연도별 차트는 막대 수가 적어 §3.4 원칙대로 상시 라벨을 유지한다.

## E4. 연도별 차트 (§11.3)

```
질문             해가 갈수록 매장이 성장하는가 축소되는가?
지원하는 결정    장기 추세 판단, 연간 목표 설정
데이터 출처      RevenueAggregate(granularity: "yearly")
갱신 시점        페이지 로드
빈 상태          거래가 전혀 없으면 "매출 기록이 없습니다"
오류 상태        위와 동일
왜 이 차트 유형  연도는 이산 구간 크기 비교 = 세로 막대.
```

**형태:** 세로 막대. **데이터가 있는 연도만** 그린다 (실측 2020~2026 = 7개). 없는 연도를 0으로 채워 넣지 않는다.

**정렬:** 항상 오름차순 연도. 금액순 금지.

**진행 중 연도:** 2026은 8월까지의 부분 데이터다. 막대 + **"진행 중" 라벨** 명시. 2025(46.2M)와 2026(25.7M)을 완결된 값으로 비교하면 오독한다.

**YoY:** 각 막대 위. 진행 중 연도는 YoY를 **표시하지 않는다** — 부분 대 전체 비교는 무의미하다. 대신 "8월까지" 표기.

**상호작용:** 막대 클릭 → 해당 연도 월별 차트 (`/sales?view=year&cursor=YYYY-01-01`).

## E6. KPI 스트립

5칸 유지 (총 매출 / 실결제 / VAT / 지출 / 샵 수익). 변경점:

1. **문자열 키 결합 제거.** 현행 `settlement.find(row => row.name === "총 매출")`(A3-8)를 서버 집계의 명시적 필드(`summary.gross` 등)로 교체.
2. **총 매출에만 델타 추가.** 선택 기간 대비 직전 동일 길이 기간. 5칸 전부에 델타를 달면 노이즈다.
3. VAT·지출이 0일 때 회색 처리. 실측상 실데이터에서 항상 0이다.

## E8. 접근성

- 모든 차트에 sr-only 미러 테이블. 기존 `DataTable`(`:157-177`) 패턴 재사용 — **삭제 금지**.
- 클릭 가능한 데이터 포인트는 `<button>`. 좌우 화살표로 포인트 간 이동.
- 상태를 색으로만 전달하지 않는다 — "진행 중", "데이터 없음"은 텍스트 라벨 병기.
- 차트 카드는 `<section aria-labelledby>`.
- 대비 4.5:1. `lib/visual-tokens.ts`가 런타임 강제.

## E9. 토큰 준수
